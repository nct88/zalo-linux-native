# Development

## Requirements

- Node.js 20 or later (CI uses 22), npm
- Rust (`rustup`), `build-essential`, `liblzma-dev`, `p7zip-full`, `zsync` (for the native addons and packaging)
- For calls: `python3`, libopus, `pulseaudio-utils` (PipeWire's `pipewire-pulse` is the server)

```bash
sudo apt install build-essential liblzma-dev p7zip-full zsync python3 libopus0 pulseaudio-utils
```

## Build and run

```bash
npm ci
npm run main:setup    # Zalo version → DMG into temp/ → app/ extracted and patched
npm start             # run from source
npm run main:build    # app/ → dist/Zalo-Linux-Native-<version>-<arch>.AppImage
```

`npm run main` does both steps. `ZALO_VERSION=26.9.10 npm run main:setup`
builds a given Zalo version (default: the latest macOS release);
`FORCE_DOWNLOAD=1` downloads the DMG again. With several DMGs in `temp/`,
`npm run prepare-app` asks which one to use.

## Releases

The version is `package.json`'s. CI builds every push to `main` and every
pull request (artifacts only). To publish:

```bash
npm version 1.0.1 --no-git-tag-version   # or edit package.json
git commit -am "release: 1.0.1"
git tag v1.0.1 && git push && git push --tags
```

The tag must match `package.json`; the workflow builds x86_64 and aarch64
and publishes the release with both AppImages and their `.zsync` files.
The AppImages carry update information for this repository's releases.

## Patches

Each change to Zalo's code is a script in `scripts/patches/` exporting
`main()`, listed in order in `PATCHES` (`scripts/prepare-app.js`). A patch
looks for the exact code it changes. When a partial change would break
something, change nothing at all — see `patch-zcall-native.js`. The call
patches (`patch-zcall-native`, `patch-zcall-callgate`) fail the build when
they do not apply, so a Zalo update cannot ship without working calls.

## Calls

`zcall-native/` is generated by `tools/export-engine.sh` of the engine's
research repository (protocol notes, captures, tests); change the engine
there and export again. `plugins/zcall/` (engine environment, call window)
belongs to this repository. Call logs:
`~/.config/ZaloData/native-engine-YYYYMMDD.log` (`ZCALL_VERBOSE=1` for whole
messages, which contain ids — keep them private).

## Debugging

- DevTools: `Ctrl+Shift+I` in the Zalo window, or the tray menu.
- Main process output: run `npm start` in a terminal.
